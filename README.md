<h2 align="center">⚡ RDX CALL - Educational Terminal Tool ⚡</h2>

**RDX CALL** হলো একটি Python-ভিত্তিক টার্মিনাল টুল, যা তৈরি করা হয়েছে সম্পূর্ণ **Educational & Learning Purpose**-এর জন্য। This project is strictly built for beginners and cybersecurity students to understand how terminal-based applications work behind the scenes.

<!-- DIVIDER -->
<img src="https://user-images.githubusercontent.com/73097560/115834477-dbab4500-a447-11eb-908a-139a6edaec5c.gif" width="100%">

## 🎯 What You Can Learn (কী কী শিখতে পারবেন)

<table align="center">
<tr>
<td>

- 🐍 **Python `requests` Library:** HTTP GET রিকোয়েস্ট পাঠানো ও রেসপন্স হ্যান্ডেল করা।
- 🔄 **User-Agent Rotation:** কীভাবে আলাদা আলাদা ইউজার-এজেন্ট স্ট্রিং তৈরি করে রিকোয়েস্ট পাঠানো হয়।
- 🎨 **Terminal UI & Animation:** ANSI Escape Codes ব্যবহার করে টার্মিনালে সুন্দর ব্যানার, প্রোগ্রেস বার ও স্পিনার তৈরি করা।
- 🧵 **Threading in Python:** মেইন প্রোগ্রাম ব্লক না করে ব্যাকগ্রাউন্ডে অ্যানিমেশন চালানো।
- 🔍 **Input Validation:** Regex (`re`) ব্যবহার করে ফোন নম্বর ফরম্যাট ও ভ্যালিডেট করা।

</td>
</tr>
</table>
